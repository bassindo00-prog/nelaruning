🔍 TROUBLESHOOTING

Issue: Bot not running after Windows restart
Solution:
  1. Check startup scripts exist: ls "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup"
  2. Test manually: pm2 resurrect
  3. Check logs: cat c:\Users\avelin\Downloads\RUN\runninghub-telegram-bot\logs\startup.log
  4. If manual resurrect works: startup script just didn't run (Windows issue, try restarting again)

Issue: Bot crashes frequently
Solution:
  1. Check memory: pm2 monit
  2. If > 500MB: Increase max_memory_restart in ecosystem.config.cjs
  3. Check logs: pm2 logs nadinmotion-bot

Issue: Want to disable autostart
Solution:
  1. Delete startup scripts: Remove "pm2-resurrect.*" from Startup folder
  2. Or: pm2 unstartup (uninstalls registry entry if exists)
